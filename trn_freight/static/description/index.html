Comprehensive Feature List

Freight Shipping Operations

  • Full order workflow: Draft → Submitted → Confirmed → Invoiced → Delivered → Closed.
  • Tracking number auto-generation with customizable sequences.
  • Direct link to consignor, consignee, and freight forwarder partners.
  • Customs clearance status tracking and verification badges.

Pricing & Cost Estimation

  • Rule-based freight pricing by route, container type, or weight/volume.
  • Cost breakdown lines: Ocean/Air freight, Terminal Handling (THC), documentation, inland haulage.
  • Real-time profit margin calculation before order confirmation.
  • Direct integration with Odoo Account Invoicing.

Executive OWL Dashboard

  • Real-time reactive KPIs built on OWL 3.0 framework.
  • Preset filters: Today, This Week, This Month, Last Month, This Quarter, This Year, All Time.
  • Custom date range selection (From Date & To Date).
  • Modal-less interactive drill-down to filtered shipping records.

Installation & Compatibility

1. Download and extract the module directory into your Odoo 18 addons path.
2. Activate Developer Mode in Odoo Settings.
3. Navigate to Apps → Update Apps List.
4. Search for Freight Management System and click Activate.

Dependencies: Base, Web, UoM, Mail, Product, Account. (No proprietary third-party libraries required).
